# 最终版 STEP 汇总

本文件夹集中保存当前项目中可交付的最终版 STEP 文件；原始文件仍保留在各自模型目录中。文件名使用中文分类前缀，便于按类别排序。

| 类别 | 文件 |
|---|---|
| 六角杆接口 | `01_六角杆接口_法兰_D20_H10_bore6p2.step` |
| 挂耳耳机 | `02_挂耳耳机_右耳挂主体.step`、`02_挂耳耳机_右耳挂总成.step` |
| 插头 | `03_插头_TypeC定位头_延长2mm.step` |
| 舵机固定架 | `04_舵机固定架_主支架.step`、`04_舵机固定架_上压片.step`、`04_舵机固定架_下压片.step`、`04_舵机固定架_总成.step` |
| 盒子和盖子 | `05_盒子_盒体.step`、`05_盒子_盒盖.step`、`05_盒子_盒体盒盖总成.step` |

本次没有复制奶龙、奶蛋或其他装饰模型，也没有复制显示器外廓参考包络 STEP。六角杆接口按项目现有 `flange_20mm` 最终实体归档，源文件名为 `flange_D20_H10_bore6p2.step`。
